maiúsculo, extensão `.JPG` — ex.: `MB-001.JPG`, `VG-001.JPG`.

na planilha nem rodar `build.py`. Só salvar o arquivo aqui e recarregar a
página. (Detalhes e exceções no README principal da pasta do site.)
