Coloque aqui as fotos dos itens, numeradas a partir de 1, no formato
`<código>-N.JPG` — ex.: `MB-001-1.JPG`, `MB-001-2.JPG`, `VG-001-1.JPG`.

Pode ter quantas fotos quiser por item (até 8 por padrão). O site já procura
automaticamente pelo código, sem precisar mexer na planilha nem rodar
`build.py`. Só salvar os arquivos aqui e recarregar a página — clicando numa
foto no site, ela abre em zoom, com setas pra navegar entre as fotos do
mesmo item. (Detalhes e exceções no README principal da pasta do site.)
